## 👤 About Me

> Systems engineer dedicated to **high-performance computing**, **pure-Rust DAW architecture**, **real-time audio DSP**, and **biomechatronics**. I care deeply about clean, deterministic architecture, lock-free concurrency, cache-conscious data layout, and building resilient software that never crashes.

- 🎯 **Primary Focus:** Low-Latency Audio Engines · Multithreaded Concurrency · Biomechatronic Assistive Robotics · Scalable Cloud Systems
- 💼 **Open Source:** Major contributor to **[SoundCraft](https://github.com/storytold/soundcraft)** (clean-room pure-Rust DAW targeting Pro Tools parity)
- 🌱 **Core Arsenal:** Rust, Modern C++, Python, WebAssembly, Go, Linux Systems
- ☕ **Philosophy:** *"Every bug is a chance to improve. Every project a step forward."*
