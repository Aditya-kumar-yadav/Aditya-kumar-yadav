## 👤 About Me

> Systems engineer dedicated to **high-performance computing**, **pure-Rust DAW architecture**, **real-time audio DSP**, and **biomechatronics**. Passionate about deterministic architecture, lock-free concurrency, cache-conscious data layout, and building resilient software that never crashes.

- 🎯 **Primary Focus:** Low-Latency Audio Engines · Multithreaded Concurrency · Biomechatronic Assistive Robotics · Scalable Cloud Systems
- 💼 **Open Source:** Contributor to **[microsoft/vscode](https://github.com/microsoft/vscode)**, **[mlflow](https://github.com/mlflow/mlflow)**, **[langfuse](https://github.com/langfuse/langfuse)**, and core author of **[SoundCraft](https://github.com/storytold/soundcraft)** (pure-Rust DAW).
- 🌱 **Core Arsenal:** Rust, Modern C++, Python, TypeScript, Next.js, WebAssembly, Go, Linux Systems
- ☕ **Philosophy:** *"Every bug is a chance to improve. Every project a step forward."*
